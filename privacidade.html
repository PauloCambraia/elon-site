Política de privacidade

Integralis Elon · em vigor desde 27/10/2026

1. Quem usa

O Elon roda no computador do próprio dono. Só o dono conecta contas a ele. Não há usuários de fora nem cadastro público.

2. Dados do Google que o Elon lê

  • Agenda (calendários que o dono possui): título e horário dos eventos.
  • Gmail: remetente, assunto, data e um trecho; o texto inteiro só quando o dono pede um e-mail.
  • Drive, Docs e Sheets, só leitura, se o dono ligar.
  • Tarefas, Contatos, YouTube e Meet, se o dono ligar cada um.
  • O e-mail da conta, para mostrar qual conta está conectada.

3. O que o Elon faz com esses dados

  • Responde ao dono. Nada mais.
  • Cria ou muda evento e move e-mail de marcador só com a confirmação do dono. O Elon não envia e-mail e não apaga nada para sempre.
  • Não vende, não aluga e não usa esses dados para anúncio.
  • Não usa esses dados para treinar modelo de IA.

4. Onde os dados ficam

O acesso salvo da conta Google fica só no computador do dono, numa pasta fechada. Os eventos e e-mails lidos para responder não ficam guardados: o Elon lê na hora da pergunta. Se o dono ligar o governador da caixa de entrada, ele guarda no mesmo computador, por 14 dias, a hora, o nome do remetente e o assunto cortado de cada e-mail que avaliou.

5. Para quem os dados vão

Para responder, o Elon manda a pergunta do dono e o trecho lido ao modelo de IA que ele escolheu: a Integralis (integralislabs.com) ou a Anthropic. O dono pode ligar também:

  • a voz da Microsoft Azure, que recebe a frase falada;
  • o Jev (TypeSafe AI), que recebe nome, assunto e trecho dos e-mails novos;
  • o Open-Meteo, que recebe a cidade, para o clima;
  • o Google Routes, que recebe os endereços, para o trânsito.

Nenhum dado vai a outra pessoa ou empresa.

6. Uso limitado (Google API Services User Data Policy)

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguem a Google API Services User Data Policy, inclusive os requisitos de Uso Limitado.

7. Como tirar o acesso

  • No Elon: armário, "Desconectar". O Elon revoga o acesso no Google e apaga o que guardou.
  • No Google: myaccount.google.com/permissions.
